# ColdMail Sender

유튜버·인플루언서 협업 제안 메일을 수신자별로 이름/채널명을 바꿔 넣어 한 통씩 발송하는 메일머지 프로그램.
열 이름은 자유라서 `회사명`/`담당자명`으로 바꾸면 일반 업무 메일(영업·제휴 제안)에도 그대로 쓸 수 있습니다.

## 설치 / 실행

**동료(Python 없는 PC)**: `ColdMailSender_Setup_<버전>.exe` 실행 → 다음/설치. 관리자 권한이 필요 없고,
Claude 데스크톱·Claude Code 가 깔려 있으면 Claude 연동도 자동으로 설정됩니다(설치 후 Claude 를 완전히 종료했다 다시 실행).
Claude 를 나중에 설치했으면 시작 메뉴의 `ColdMail Sender Claude 연결`을 실행하세요.
서명되지 않은 프로그램이라 "Windows의 PC 보호" 창이 뜨면 `추가 정보` → `실행`을 누릅니다.
업데이트는 새 설치 파일을 그냥 실행하면 되고, 데이터는 그대로 남습니다(제거해도 남음).

**소스 버전(개발용)**:

1. `setup.bat` 더블클릭 (처음 한 번, 그리고 프로그램을 업데이트한 뒤). Python 3.10 이상 필요.
2. 이후에는 **바탕화면 또는 시작 메뉴의 `ColdMail Sender`** 아이콘으로 실행합니다.
   주소창 없는 독립 창으로 열리고, 창을 닫으면 3분 뒤 백그라운드 서버도 스스로 종료됩니다
   (발송 중이면 발송이 끝날 때까지 유지).

## 처음 시작하기 (샘플)

처음 실행하면 샘플이 자동으로 들어 있습니다. 그대로 `발송` 탭에서 템플릿·리스트를 고르고 `수신자 확인`을 누르면
치환·조사 교정·이름 합치기가 어떻게 되는지 미리보기로 바로 볼 수 있습니다.

| 샘플 | 내용 |
|---|---|
| 수신자 리스트 `샘플_수신자` | 4명. 받침 없음/있음/ㄹ받침 채널명, 채널명≈이름인 경우, `맞춤문단 1~5` 열(사람마다 1~5개 사용) |
| 템플릿 `협업제안_기본.md` | 마크다운 협업 제안 기본안 (모두에게 같은 본문) |
| 템플릿 `협업제안_맞춤형.md` | 공통 틀 + `{{맞춤문단 1}}` ~ `{{맞춤문단 5}}` (수신자마다 다른 문단, 빈 것은 생략) |
| 템플릿 `협업제안_상세.docx` | Word 협업 제안 (제목·목록·표 포함) |

샘플 주소는 모두 `@example.com`(실제로 받을 수 없는 주소)이니, 자신의 리스트로 바꿔서 쓰세요.
원본 파일은 `samples/` 폴더에 있고, 샘플을 지워도 다시 생기지 않습니다.

## 사용 순서

1. **설정**: SMTP(발송 서버) 정보 입력 → `저장 후 연결 테스트`
   - 이카운트: SMTP `wsmtp.ecount.com` / 587 / STARTTLS, IMAP `wmbox3.ecount.com` / 993 (웹메일 비밀번호)
   - Gmail: `Gmail` 프리셋 → 계정 + **앱 비밀번호**
2. **메일 템플릿**: 마크다운으로 작성하거나 `.md`/`.docx` 파일 업로드
3. **수신자 리스트**: 엑셀/CSV 가져오기, 구글시트 가져오기, 직접 입력, 엑셀에서 복사 → `Ctrl+V`. `이메일` 열 필수.
   양식이 필요하면 탭 안내문의 **샘플 양식(엑셀/CSV)** 링크로 받으세요.
   칸을 **더블클릭**하면 긴 글 편집창이 열립니다(여러 줄 입력 가능). 여러 줄인 칸은 표에 `⏎`로 표시되고, 클릭하면 편집창이 열립니다.
4. **발송**: 템플릿·리스트·제목 선택 → `수신자 확인` → 미리보기 → `테스트 발송` → `발송 시작`

## 치환 필드, 조사 자동 교정, 이름 합치기

리스트의 열 이름을 제목/본문에 `{{열이름}}` 으로 쓰면 수신자별 값으로 바뀝니다.
치환 필드 **바로 뒤에 붙인 조사**는 받침에 맞게 자동으로 고쳐집니다.

```
{{채널명}}가 저희와 함께  →  쯔양이 저희와 함께 / 안원잘부가 저희와 함께
{{채널명}}과 협업         →  쯔양과 협업 / 안원잘부와 협업
{{채널명}}(을)를 응원     →  쯔양을 응원 / 안원잘부를 응원
```

지원: 은/는, 이/가, 을/를, 과/와, 으로/로(ㄹ받침 포함), 이랑/랑, 이나/나, 이라/라, 이며/며, 이에요/예요, 이었/였, 이여/여.
`이/가`, `(이)가` 처럼 써도 됩니다. 숫자는 읽는 소리로(채널7 → 칠 → 이), 영문은 마지막 알파벳 이름으로 판단하므로
영어 단어 채널명(예: Google → 구글)은 틀릴 수 있습니다. 미리보기에서 확인하세요.

**이름 합치기**: 공백만 사이에 둔 두 치환 필드의 값이 사실상 같으면 짧은 쪽(보통 이름) 하나만 남깁니다.
"사실상 같다"는 값이 같거나, 한쪽에 2글자 이하(TV, 채널, 공식 등)만 더 붙은 경우입니다.

```
{{채널명}} {{이름}} 님   채널명=고재영,      이름=고재영  →  고재영 님        (고재영 고재영 님 X)
                        채널명=고재영TV,    이름=고재영  →  고재영 님
                        채널명=민지의 하루, 이름=김민지  →  민지의 하루 김민지 님
                        채널명=고재영의 일상, 이름=고재영 →  고재영의 일상 고재영 님 (3글자 이상 차이)
```

## 수신자마다 다른 내용 쓰기 (맞춤 문단)

사람마다 다른 내용은 **수신자 리스트의 열**에 넣고, 템플릿은 **공통 틀**만 둡니다. 별도 파일을 만들지 않습니다.
한 번의 발송으로 처리되고, 발송 기록·중복 방지·발송 간격이 그대로 적용됩니다.
맞춤 문단은 `맞춤문단 1` ~ `맞춤문단 5` 처럼 여러 개 둘 수 있습니다(개수 제한 없음, 5개 권장).

| 회사명 | 담당자명 | 이메일 | 제목 | 맞춤문단 1 | 맞춤문단 2 | … | 맞춤문단 5 |
|---|---|---|---|---|---|---|---|
| 민지의 하루 | 김민지 | … | 민지의 하루 × ○○ 겨울 캠페인 제안 | 지난달 올리신 '겨울 루틴' 영상에서… | 보습 라인을 아침 루틴에… | | 추운 날씨에 건강 유의하시고… |

```
안녕하세요, {{회사명}} {{담당자명}} 님.
저는 ○○브랜드 마케팅팀의 홍길동입니다.

{{맞춤문단 1}}          ← 연락 계기 (최근 콘텐츠·사업 언급)

{{맞춤문단 2}}          ← 제안 아이디어

{{맞춤문단 3}}          ← 기대 효과

(공통 회사 소개 · 조건)

{{맞춤문단 4}}          ← 조건·일정 관련 개별 메모

{{맞춤문단 5}}          ← 마무리 한마디

(서명)
```

- **열 이름이 `맞춤문단`으로 시작하면 선택 항목**입니다. 비어 있으면 그 문단이 통째로 빠지고(빈 줄도 남지 않음),
  발송 대상에서도 빠지지 않습니다. 사람마다 필요한 만큼만 채우면 됩니다. 수신자 확인 목록에 `생략: 맞춤문단 3` 처럼 표시됩니다.
  (이름·회사명 같은 다른 열이 비어 있으면 지금처럼 `빈 값` 경고가 뜨고 기본 선택에서 빠집니다.)
- 각 `{{맞춤문단 N}}` 은 앞뒤를 빈 줄로 띄워 **단독 문단**으로 두세요. 그래야 비었을 때 깔끔하게 빠집니다.
- 열 이름과 템플릿의 `{{ }}` 이름은 띄어쓰기까지 같아야 합니다(`맞춤문단 1` ≠ `맞춤문단1`). 다르면 수신자 확인 때 "리스트에 없는 치환 필드" 경고가 뜹니다.
- 번호 없이 `맞춤문단` 하나만 써도 됩니다.
- 발송 탭의 제목 칸에 `{{제목}}` 을 넣으면 제목도 수신자마다 달라집니다.
- 칸 안의 **줄바꿈은 메일에서도 줄바꿈**, 빈 줄은 문단 간격이 됩니다. 제목 칸의 줄바꿈은 공백으로 바뀝니다.
- 칸 안의 마크다운(`**굵게**`, `[링크](주소)`)은 적용되지 않고 글자 그대로 나옵니다. 서식은 템플릿 쪽에 두세요.
- 칸 안의 조사는 자동 교정되지 않습니다(교정은 템플릿의 `{{열이름}}` 바로 뒤에서만).
- 메일 전체가 사람마다 다르면 템플릿을 `{{본문}}` + 서명만 두고 `본문` 열에 전체를 쓰세요.
- 버전이 몇 가지뿐이면(예: 뷰티/푸드) 버전별 템플릿을 만들고 수신자를 나눠 따로 발송해도 됩니다.
- 입력: 앱 표에서 칸 더블클릭, 엑셀/구글시트 셀에서 Alt+Enter 로 줄을 바꿔 작성 후 가져오기, 또는 Claude가 MCP로 작성.

## 구글시트

시트 공유를 **'링크가 있는 모든 사용자 - 뷰어'** 로 설정하고 주소를 붙여넣습니다. 여러 탭이면 가져올 탭을 연 상태의 주소를 쓰세요.
가져온 리스트는 `시트에서 다시 불러오기`로 최신 내용을 다시 받을 수 있습니다(앱에서 고친 내용은 덮어써짐).
링크를 아는 사람은 누구나 시트를 볼 수 있으니, 비공개로 두려면 아래 Claude 연동으로 넣으세요.

## Claude(Claude Code / Cowork) 연동

MCP 서버(`mcp_server.py`)를 등록하면 어느 폴더의 Claude 세션에서든 이 프로그램을 쓸 수 있습니다.
사용법(맞춤 문단 패턴, 작성 규칙, 작업 순서)은 MCP 서버가 Claude에게 직접 알려주므로 따로 설명할 필요가 없습니다.

**등록** (`setup.bat` 마지막에도 출력됩니다)
- Claude Code: `claude mcp add coldmail-sender --scope user -- "%LOCALAPPDATA%\ColdMailSender\venv\Scripts\python.exe" "<이 폴더>\mcp_server.py"`
  - 확인: `claude mcp list` / 제거: `claude mcp remove coldmail-sender --scope user`
- Claude 데스크톱(Cowork): 설정 → 개발자 → 구성 편집 → `mcpServers` 에 `setup.bat` 이 출력한 JSON 추가 후 재시작

**Claude가 쓰는 도구**

| 도구 | 하는 일 |
|---|---|
| `overview` | 템플릿·리스트·첨부·보내는 계정·발송 대기·진행 중 발송 확인 |
| `get_list` / `save_list` | 리스트 읽기 / 행 추가(append)·교체(replace). 행은 `{열이름: 값}` |
| `import_google_sheet` | 공유된 구글시트를 리스트로 |
| `get_template` / `save_template` | 템플릿 읽기 / 마크다운 템플릿 저장 |
| `preview` | 문제 행 점검, 생략되는 맞춤문단 목록, `row_numbers` 행들의 실제 제목·본문 |
| `send_test` | 해당 행 기준 메일을 **보내는 사람 본인 주소로만** 테스트 발송 |
| `queue_campaign` | 발송 대기에 올리기 |
| `send_history` | 발송 기록 조회 (이미 연락한 사람 확인) |

**다른 세션에서 Claude에게 시키는 예**
> "취합한 채널 20곳을 ColdMail Sender 리스트 '12월_뷰티'로 만들고, 채널마다 맞춤문단 1~3(연락 계기, 제안 아이디어,
> 기대 효과)을 써서 협업제안_맞춤형 템플릿으로 전부 미리보기 후 발송 대기에 올려줘"

실제 발송은 사람이 앱의 `발송` 탭 → `발송 대기` → `불러오기` → 확인 후 `발송 시작`을 누릅니다.
Claude가 대량 발송을 직접 시작하는 도구는 없습니다(의도된 설계). 비공개 구글시트는 Claude의 구글 드라이브 연결로
읽어서 `save_list` 로 넣으면 시트를 공개하지 않아도 됩니다. 메일 계정 설정은 앱의 설정 탭에서 사람이 합니다.

## 안전장치

- 메일마다 설정한 범위(기본 5~20초)에서 무작위로 대기
- 받는 메일 서버(MX)가 Google(Gmail·Workspace)이나 Microsoft(Outlook·365)면 같은 회사로 가는 메일끼리는
  더 긴 간격(기본 30~90초)을 두고, 그동안 다른 주소를 먼저 보냄. 회사 도메인 주소도 메일 서버로 판별하고,
  조회에 실패하면 긴 간격 쪽으로 취급
- 주소 오류·리스트 내 중복 자동 제외, 이전 발송 성공 주소는 기본 선택 해제
- 3회 연속 실패 시 자동 중단, 발송 중 언제든 `중지` 가능, 결과는 `발송 기록` 탭에 저장

## 파일 구성

| 파일 | 역할 |
|---|---|
| `setup.bat` / `install.py` | 패키지 설치, 바탕화면·시작 메뉴 바로가기 생성, Claude 연동 안내 출력 |
| `launcher.pyw` | 아이콘이 실행: 서버를 백그라운드로 띄우고 앱 창(Edge 앱 모드)을 연다. 설치판 exe 의 진입점(`--server`/`--mcp`/`--register-mcp`) |
| `build.bat` / `installer.iss` | 배포용 설치 파일 만들기 (PyInstaller → Inno Setup) |
| `claude_setup.py` | 설치판: Claude 데스크톱·Claude Code 설정에 MCP 서버 등록/해제 |
| `app.py` | 로컬 서버(127.0.0.1:8765): 화면용 API, 발송 작업 실행, 유휴 시 자동 종료 |
| `mailer.py` | 템플릿 변환(md/docx→HTML), 치환·조사 교정·이름 합치기, 메일 생성, SMTP/IMAP, 받는 메일 서버 판별 |
| `store.py` | 설정·비밀번호·템플릿·리스트·첨부·발송 대기·발송 기록 저장, 엑셀/CSV/구글시트 읽기 |
| `mcp_server.py` | Claude 연동용 MCP 서버 (app.py 의 API 를 프로세스 안에서 직접 호출) |
| `static/` | 화면 (index.html, app.js, style.css, 아이콘) |
| `samples/` | 샘플 수신자 리스트(xlsx/csv)와 템플릿(md/docx). 첫 실행 때 앱에 들어가고, 리스트 탭의 '샘플 양식' 링크로도 받음 |

## 데이터 위치

| 내용 | 위치 |
|---|---|
| 설정 (비밀번호 제외) | `data/settings.json` |
| 비밀번호 | Windows 자격 증명 관리자 (`ColdMailSender`) — 파일에 저장하지 않음 |
| 템플릿 / 리스트 / 첨부 / 발송 대기 | `data/templates/`, `data/lists/`, `data/attachments/`, `data/queue.json` |
| 발송 기록 | `data/sendlog.db` |
| Python 가상환경, 서버 로그, 앱 창 프로필 | `%LOCALAPPDATA%\ColdMailSender\` (OneDrive 동기화 제외) |

설치판은 위의 `data/` 대신 `%LOCALAPPDATA%\ColdMailSender\data\` 를 씁니다. 프로그램은 `%LOCALAPPDATA%\Programs\ColdMail Sender\`.

## 배포용 설치 파일 만들기

1. (처음 한 번) `setup.bat`, 그리고 `winget install JRSoftware.InnoSetup --scope user`
2. `build.bat` 더블클릭 → `release\ColdMailSender_Setup_<버전>.exe` (약 23MB). 이 파일 하나만 동료에게 전달합니다.
3. 새 버전을 낼 때는 `installer.iss` 의 `AppVersion` 을 올리고 다시 빌드합니다.

개발 PC에서는 설치 파일을 실행하지 마세요. Claude 연동 등록이 소스 버전 대신 설치판을 가리키게 바뀌고,
같은 포트(8765)를 써서 소스 버전과 설치판 앱이 서로의 서버에 붙습니다.
