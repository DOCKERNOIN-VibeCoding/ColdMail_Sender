    3. 수신자

    행을 클릭하면 해당 수신자 기준으로 미리보기가 바뀝니다.
    맨 윗줄은 열 이름입니다. '이메일' 열이 필요하고, 열 이름을 제목/본문에 {{열이름}} 으로 쓰면 수신자별 값으로 바뀝니다. 엑셀에서 여러 칸을 복사해 칸을 클릭하고 Ctrl+V 하면 그 위치부터 채워집니다 (머리글 칸에 붙이면 첫 줄이 열 이름).
    칸을 더블클릭하면 긴 글 편집창이 열립니다. 수신자마다 다른 내용은 맞춤문단 1 ~ 맞춤문단 5 열에 쓰고 템플릿에 {{맞춤문단 1}} … 으로 넣으세요 (줄바꿈 유지, 빈 맞춤문단은 그 문단을 빼고 발송).
    샘플 양식: 엑셀 · CSV
    Word 문서는 여기서 편집할 수 없습니다. '폴더 열기'로 파일을 Word에서 직접 고친 뒤 이 탭을 다시 열면 반영됩니다.
    줄바꿈은 그대로 유지됩니다. 굵게: **텍스트**, 링크: [텍스트](https://...)
    조사는 자동으로 맞춰집니다: {{채널명}}가 → 쯔양이 / 안원잘부가 (은/는, 을/를, 과/와, 으로/로 등. 치환 필드 바로 뒤에 붙여 쓰세요)
    채널명과 이름이 거의 같으면 하나만 나옵니다: {{채널명}} {{이름}} 님 → 고재영TV + 고재영 = 고재영 님
    수신자마다 다른 내용은 리스트의 맞춤문단 1~5 열에 쓰고 여기에 {{맞춤문단 1}} … 을 각각 빈 줄로 띄운 단독 문단으로 넣으세요. 빈 것은 문단째 생략됩니다 (예: 협업제안_맞춤형.md)

    발송 서버 (SMTP)

    프리셋:
    비밀번호는 파일이 아니라 Windows 자격 증명 관리자에 저장됩니다. Gmail은 일반 비밀번호 대신 앱 비밀번호(Google 계정 → 보안 → 2단계 인증 → 앱 비밀번호)를 사용하세요.

    보낸편지함 저장 (IMAP, 선택)

    Gmail은 자동으로 보낸편지함에 저장되므로 끄세요(켜면 두 번 저장됨). 회사 메일은 보낸 기록이 남지 않는 경우가 많아 켜는 것을 권장합니다.

    발송 간격

    모든 메일 사이에 기본 간격(5~20초 권장)을 무작위로 둡니다. 받는 메일 서버가 Google(Gmail·Workspace)이나 Microsoft(Outlook·365)이면 같은 회사로 가는 메일끼리는 더 긴 간격(30~90초 권장)을 두고, 그동안 다른 주소를 먼저 보냅니다. 너무 짧으면 스팸 판정이나 계정 일시 정지 위험이 커집니다.

    Enter로 줄바꿈, 빈 줄로 문단을 나눕니다. 메일에도 그대로 반영됩니다. (Ctrl+Enter: 적용)
